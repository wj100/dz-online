# 德州扑克 · 多人在线（dz-online）

一款支持多人在线对战的德州扑克现金局游戏。玩家注册后创建房间、邀请好友凭邀请码加入，进行实时对局；对局数据自动入库，提供历史对局与排行榜统计。

## 一、功能特性

- **账号系统**：注册 / 登录（JWT 鉴权 + bcrypt 密码加密），注册即送 1000 虚拟筹码
- **房间机制**：创建房间生成 6 位邀请码，好友凭码加入
- **灵活人数**：默认「灵活」模式，座位动态分配（上限 9 人），玩家随时加入 / 离开；也支持固定 2 / 3 / 4 / 6 / 9 人桌
- **盲注可选**：5/10、10/20、25/50
- **完整牌局**：翻牌前 → 翻牌 → 转牌 → 河牌 → 摊牌，标准四街下注
- **完整边池**：支持多人 all-in 边池拆分、弃牌者筹码进池、超额退还、平局分池
- **操作**：弃牌 / 过牌 / 跟注 / 加注 / 全下，加注滑块
- **重新买入（rebuy）**：桌上筹码低于 100 时显示按钮，免费补充 1000 虚拟筹码
- **断线 / 超时托管**：断线或 30 秒未操作，自动过牌或弃牌，重连自动恢复
- **数据统计**：历史对局记录（日期、玩家人数、每人买入 / 盈亏 / 入池率）+ 排行榜（积分、胜率）

## 二、游戏规则

### 1. 对局模式

- **现金局（Cash Game）**：盲注固定不随时间上涨，无淘汰，可随时 rebuy 继续游戏
- 牌型从高到低：皇家同花顺 → 同花顺 → 四条 → 葫芦 → 同花 → 顺子 → 三条 → 两对 → 一对 → 高牌
- 支持 A-2-3-4-5「轮子」顺子（5 高顺子）
- 两人对局（heads-up）时，庄家兼任小盲

### 2. 下注规则

- 小盲（SB）、大盲（BB）按庄家顺时针轮转
- 最小加注幅度 = 上一次加注的增量（标准 No-Limit 规则）
- 全下（all-in）不足一个最小加注时，不重新开启下注轮

### 3. 边池与结算

- 多个玩家 all-in 金额不同时，自动拆分主池与多个边池
- 弃牌者投入的筹码进入底池，但无赢取资格
- 全下超额部分自动退还（通过独占边池实现）
- 平局分池，奇数筹码按座位顺序逐个分配

## 三、筹码与买入规则

| 项 | 规则 |
|---|---|
| 筹码性质 | 纯虚拟币，不涉及真实资金 |
| 初始筹码 | 注册赠送 1000 |
| 上桌买入（buy-in） | 加入房间时买入 1000（若银行余额不足则全部买入） |
| 重新买入（rebuy） | 桌上筹码 < 100 时，免费补充 1000 |
| 离桌结算 | 离开房间时，桌上剩余筹码退回银行余额 |
| 崩溃保护 | 服务重启时自动回收未结算的买入本金 |

## 四、数据统计

每场对局结束时，自动记录每位玩家的以下指标：

| 指标 | 口径 |
|---|---|
| 买入 | buy-in + rebuy 总额 |
| 盈亏 | 最终筹码 − 买入 |
| 入池率（VPIP） | 主动入池手数 ÷ 参与手数（翻前跟注 / 加注 / 全下才算主动） |
| 胜率 | 赢的手数 ÷ 参与手数 |
| 积分 | 累计净盈亏 |

统计页面（大厅「数据统计」入口）提供：

- **排行榜**：积分排行（累计盈亏）+ 胜率排行
- **历史对局**：每场对局的日期、玩家人数，点击查看各玩家明细

## 五、技术架构

| 层 | 技术栈 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Vue Router + Socket.io-client + Naive UI |
| 后端 | Node.js + TypeScript + Express + Socket.io + Prisma + SQLite |
| 实时通信 | Socket.io（房间广播 + 逐人定制快照） |
| 数据存储 | SQLite（用户、场次、玩家结算记录） |

**架构原则**：服务端权威 —— 牌堆、发牌、下注、结算全部在服务端，客户端仅上报动作意图并渲染，杜绝客户端作弊。

## 六、快速开始

```bash
# 1. 启动服务端（端口 3001）
cd server && npm install && npx prisma db push && npm run dev

# 2. 启动前端（端口 5173）
cd client && npm install && npm run dev
```

浏览器打开 `http://localhost:5173`，注册两个账号即可开房间对局。
